# 코어닷독스 1.0.0 릴리스 노트

작성일: 2026-10-28 · 대상: Windows x64

코어닷독스 1.0은 HWPX·HWP·DOCX 문서를 열고 편집하며 AI와 함께 작업하는 Windows 데스크톱 앱입니다. 백엔드와 문서 편집기를 포함해 Docker 없이 실행하고, 도움말과 기본 문서 편집은 오프라인에서도 사용할 수 있습니다.

## 코어닷독스 전용 도움말

`F1` 또는 **도움말 → 코어닷독스 도움말**에서 시작하기, 파일과 저장, 문서 편집, AI 채팅, 외부 AI 앱 연결, 리비전, 단축키, 문제 해결을 검색할 수 있습니다. **코어닷독스 정보**에는 실제 앱 버전과 GitHub 릴리스 링크가 표시됩니다.

자동 동기화와 파일 저장의 차이, HWP를 HWPX로 변환할 때 원본을 보존하는 방법, AI 설정과 되돌리기 범위도 안내합니다. AI 요청과 외부 웹 링크에는 인터넷 연결이 필요하고, 앱 안 AI 채팅에는 사용자의 core.today API 키가 필요합니다.

## 편집 내용 보관 개선

- DOCX에서도 대기 중인 입력을 동기화한 뒤 실행 취소합니다. 동기화가 실패하면 실행 취소나 탭 닫기를 중단하고 오류를 알립니다.
- 저장 창을 열어 둔 사이에 추가로 편집한 내용은 미저장 상태로 유지합니다. 추가 입력을 확인한 뒤 다시 저장할 수 있습니다.
- HWPX·DOCX의 미동기화 입력과 외부 변경이 겹치면 입력 내용을 이름에 ‘충돌 복구’가 들어간 별도 문서로 보관합니다. **시작 화면 → 이 앱의 문서**에서 최신 문서와 복구 사본을 비교할 수 있습니다. 복구 사본을 만들지 못하면 화면의 편집 내용을 유지하고 오류를 알립니다.
- 저장하지 않고 앱을 닫을 때 마지막 입력이 사라질 수 있음을 안내합니다. 계속 보관할 내용은 파일로 저장하세요.

## PDF와 인쇄

HWPX와 DOCX 모두 **파일 → PDF로 저장…**, **파일 → 인쇄…** 메뉴와 `Ctrl+P`를 지원합니다. Windows 앱에서는 PDF 저장 위치를 선택하고, 웹판에서는 브라우저 인쇄 대화상자를 사용합니다. DOCX에는 현재 활성 문서만 출력됩니다.

DOCX 인쇄에서 불필요한 빈 페이지가 생기던 문제를 수정했습니다. 구역별 A4 세로·가로 용지, 반복 여백과 머리말·꼬리말, 페이지 번호, 그림, 각주, 두 단 문서를 실제 PDF로 검증했습니다. 인쇄 준비 과정에서도 편집 중인 문서와 선택 범위, 확대 비율을 유지합니다. 특수한 표나 개체 때문에 쪽 경계를 확정할 수 없으면 PDF 저장을 중단하고 오류를 알립니다.

## Windows 설치와 연결

1.0 설치 파일은 **현재 사용자 전용**입니다. 관리자 권한 없이 `%LOCALAPPDATA%\Programs\coredotdocs`에 설치하며, 기존 현재 사용자 설치를 업그레이드하면 등록된 설치 위치를 유지합니다. 문서 사본과 로그는 `%APPDATA%\coredotdocs`에 보관합니다.

`.hwpx`·`.hwp`·`.docx`는 ‘연결 프로그램’ 후보로 등록합니다. 기존 한글·Word의 기본 앱 선택은 유지합니다. 현재 사용자 설치·제거, 바로가기, 파일 연결 등록·정리와 사용자 데이터 보존을 실제 Windows 환경에서 확인했습니다. 최종 설치 파일의 재검증 결과는 [검증 기록](v1.0.0-validation.md)에 기록합니다.

내장 서버가 시작하지 못하거나 실행 중 종료되면 오류와 로그 위치를 알립니다. 외부 AI 앱 연결의 Windows 경로·명령 인자 처리와 기존 설정 보존도 보완했습니다. MCP 입출력을 UTF-8로 고정해 Windows에서 연결 시작이 실패하거나 한글이 잘못 전달되는 문제를 수정했고, MCP도 버전 1.0.0을 표시합니다. 프로젝트와 배포 의존성의 라이선스·저작권 고지는 설치 폴더의 `resources/licenses`에 포함됩니다. 사용하지 않는 PostgreSQL 드라이버는 SQLite 기반 데스크톱 패키지에서 제외합니다.

## 공개 전 보완

- DOCX의 외부 연결 그림은 자동으로 불러오지 않고 자리 표시자로 보여 줍니다. 편집·저장 시 원본 연결 관계는 보존합니다. 문서 발신자가 그림 URL로 열람 사실을 추적하는 요청을 방지합니다.
- 데스크톱은 현재 앱 화면에서 오는 IPC만 처리하고, 네이티브 파일 선택·드롭으로 허용된 문서 경로에만 접근합니다. 필요한 로컬 글꼴 권한 이외의 브라우저 권한은 기본적으로 거부합니다.
- Docker 포트는 `127.0.0.1`로 제한합니다. 백엔드는 Host·Origin을 검사하고 파일을 읽을 때 크기를 제한합니다. 서버는 신뢰할 수 있는 단일 사용자 로컬 환경용이며, 인터넷에 공개하는 다중 사용자 서비스가 아닙니다.
- 배포 의존성 고지를 보완하고, 출처가 불명확했던 테스트용 아이콘·로고는 자체 생성 도형으로 교체했습니다.
- 공개 커밋에는 GitHub 비공개 이메일 주소를 사용합니다. 이전 개발 이력과 배포물은 별도 비공개 저장소로 보존합니다.
- 보안 문제 신고는 [보안 정책](../../SECURITY.md)을 참고하세요.

## 검증과 배포 안내

백엔드·프런트엔드·문서 엔진·편집기·인쇄 검사와 실제 AI 통합 검사를 수행했습니다. 공개 전 보완 후 다시 실행한 검사는 검증 기록에서 이전 검증과 구분합니다. 실제 core.today API를 통한 문서 읽기·편집·재읽기·되돌리기, Microsoft Word와 한컴오피스에서 테스트 문서를 열고 저장한 뒤 코어닷독스에서 다시 읽는 왕복 호환성도 확인했습니다. 상세 버전, 범위와 증거는 [검증 기록](v1.0.0-validation.md)을 참고하세요.

설치 파일은 **코드 서명이 없는 배포본**입니다. Windows가 게시자를 확인하지 못했다는 경고를 표시할 수 있습니다. 비공개 준비 단계의 GitHub Actions는 계정 결제 또는 지출 한도로 차단되어 로컬 빌드와 테스트로 검증했습니다. 공개 이후 CI 상태는 검증 기록과 저장소 Actions에서 확인할 수 있습니다. macOS·Linux 1.0.0과 Claude Desktop·Claude Code·Codex의 실제 앱 세션 연결은 이번 검증 범위에 포함되지 않습니다.

설치 파일 이름은 `coredotdocs-1.0.0-setup.exe`입니다. 설치 없이 실행할 때는 `win-unpacked` 폴더 전체가 필요합니다. [GitHub 릴리스 페이지](https://github.com/CoreDotToday/coredotdocs/releases)에서 설치 파일과 SHA-256, 검증 기록을 확인할 수 있습니다. macOS는 보완된 소스로 별도 빌드해야 하며, 기존 Mac 패키지는 이번 공개 릴리스에 포함하지 않습니다.
