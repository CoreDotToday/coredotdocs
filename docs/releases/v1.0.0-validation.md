## 보안·개인정보·라이선스

- Docker 포트는 loopback에 연결합니다. 백엔드는 허용된 Host·Origin을 검사하고, 문서·리비전·그림·실시간 편집 결과의 파일 읽기 크기를 제한합니다. 서버는 신뢰할 수 있는 단일 사용자 로컬 환경용입니다. 전체 API에 사용자 로그인·문서별 권한 검사를 제공하는 인터넷 서비스는 아닙니다.
- 외부 연결 DOCX 그림은 DOM·인쇄 출력에서 차단합니다. 본문과 머리말의 자동 네트워크 요청이 없고, 편집·저장 후 원본 관계 XML이 유지되는지 확인했습니다.
- Electron IPC는 현재 앱의 첫 프레임만 허용합니다. 네이티브 선택·드롭으로 허용된 파일 경로를 관리하고, 필요한 로컬 글꼴 권한 이외의 권한은 기본 거부합니다.
- 소스의 출처가 불명확했던 아이콘·로고를 자체 생성 도형으로 교체했습니다. DOCX 시험 자료는 그림 1개만 바꾸고 다른 20개 ZIP 항목과 그림 크기를 보존했습니다.
- `resources/THIRD-PARTY-NOTICES.txt`, `resources/third-party-manifest.json`, `resources/licenses/`에 고지를 포함합니다. 목록은 675개 기록, 생성한 고지 텍스트 641개이며, 보수적으로 포함한 선택·개발용 네이티브 구성요소도 있어 모두가 실제 링크됐다는 뜻은 아닙니다.
- Python·WASM·복사된 배포 파일과 고지의 해시를 검사하고 누락·변조 시 패키징을 중단합니다. 데스크톱에서 사용하지 않는 PostgreSQL 드라이버와 Sharp/libvips 서버 이미지 최적화 모듈은 제외했습니다.
- 최종 배포 폴더 2,987개 파일, ZIP 내부 154개 항목, ASAR 5개 항목, Python 모듈 1,836개를 정적으로 검사했습니다. 자격증명 패턴·이전 작성자 개인 이메일 검출 0건, 파싱 오류 0건입니다. Gitleaks의 5건은 Next.js 생성 키 3개의 중복 위치로 판별했으며 서버 액션 항목은 0개입니다.
- 공개 이력은 GitHub 비공개 이메일 주소로 새로 구성합니다. 이전 개발 이력과 배포물은 별도 비공개 보관본에 남깁니다. 기존 비공개 클론의 과거 이력을 새 공개 저장소에 밀어 넣지 마세요.
- CI는 읽기 권한, checkout 인증정보 미보관, 액션 SHA 고정을 적용합니다. 비공개 준비 단계의 GitHub Actions는 결제·지출 한도로 차단됐으며 위 결과는 로컬 검사입니다. 공개 이후 실행 상태는 [Actions](https://github.com/CoreDotToday/coredotdocs/actions)에서 별도로 확인할 수 있습니다.

## 범위와 재현

코드 서명·macOS/Linux 패키지 실행·Claude Desktop/Claude Code/Codex의 실제 사용자 앱 세션 연결은 이번 Windows 공개 배포 검증 범위에 포함되지 않습니다. Mac 패키지는 해당 플랫폼의 네이티브 고지 검토와 재빌드·실행 검증 후 별도로 공개해야 합니다. 기존 Mac DMG는 포함하지 않습니다. 테스트는 대표 사례이며 모든 문서와 Office 기능의 동일한 렌더링을 보장하지 않습니다.

```powershell
node desktop/scripts/smoke-app-win.cjs desktop/dist-next/win-unpacked/coredotdocs.exe
node desktop/scripts/smoke-mcp-win.cjs desktop/dist-next/win-unpacked/coredotdocs.exe
powershell -NoProfile -ExecutionPolicy Bypass -File desktop/scripts/test-install-win.ps1 -InstallerPath desktop/dist-next/coredotdocs-1.0.0-setup.exe -Execute
```
